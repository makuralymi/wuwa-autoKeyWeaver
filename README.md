# 鸣朝古琴曲谱编辑自动播放器（keyweaver）

基于 **Tauri 2 + Rust + winapi** 的曲谱编辑与按键模拟工具：可视化编辑曲谱，播放时按曲谱自动模拟键盘按键（适用于鸣潮乐器演奏等按键盘触发的场景）。

## 功能

- 可视化曲谱编辑：自定义速度（BPM 20~600）、自定义拍号（每小节 1~16 拍）
- **支持和弦**：每个音符可填入多个同时按下的音（对应括号记谱），点音符面板或按字母键即可添加/移除
- **多分音符（时值）**：支持十六分 / 八分 / 四分 / 二分 / 全音符及附点音符，每个音符独立设置时值（四分音符为一拍，BPM 按四分音符计）
- 21 个音符：简谱 1~7 的低 / 中 / 高三个八度（低八度下加点、高八度上加点），另含休止符
- 按键映射（键盘字母区每排从左到右 7 键）：

  | 八度 | 音符 | 按键 |
  |------|------|------|
  | 高八度 | 1~7（上加点） | `Q W E R T Y U` |
  | 中八度 | 1~7 | `A S D F G H J` |
  | 低八度 | 1~7（下加点） | `Z X C V B N M` |

- **内置默认谱面**：两首预设——《远航星的告别》（by B站 掉漆桌，670 个音符事件）与《且听风吟》（MIDI 转谱，1029 个音符事件），首次启动自动加载
- 播放曲谱：按 BPM 节奏用 winapi `SendInput`（扫描码方式）模拟按下/松开和弦按键
- **多谱面管理**：新建 / 重命名（双击）/ 删除 / 快速切换，各谱面独立保存拍数与 BPM
- **倒计时**：播放前可设置 0~60 秒倒计时（留出切换到游戏窗口的时间），倒计时期间可暂停/停止
- **自动切换游戏窗口**：播放时检测 `Wuthering Waves.exe`（兼容 `Client-Win64-Shipping.exe`）进程，若在运行则直接把游戏窗口切到前台，无需手动切换
- **切屏自动停止**：演奏阶段若游戏失焦（切到其他窗口），立即自动停止发送按键，避免误发到非游戏窗口；倒计时与暂停期间不拦截。游戏未运行时保持原有行为
- **试听（音频预览）**：内置 88 键钢琴采样（Close Grand，按简谱 C 大调音阶 do-re-mi 转出的 WebM/Opus），点「🎧 试听」即可在应用内听到当前谱面的旋律与节奏（不模拟按键、不进游戏），与播放同样高亮当前音符、锁定编辑
- **系统托盘**：关闭主窗口时弹出确认（完全退出 / 最小化到托盘）；最小化到托盘后应用继续在后台运行，托盘图标左键单击或菜单「显示主窗口」恢复，菜单「完全退出」结束进程
- **悬浮窗**：置顶无边框小窗，可拖拽，展示当前谱名，含 开始 / 暂停 / 结束 / 倒计时调整 / 切换谱面；播放时实时显示倒计时与当前拍进度
- 播放时主界面实时高亮当前拍；暂停时自动松开按键、恢复时重新按下
- **播放时禁止编辑**：播放期间音符面板、BPM/拍数/倒计时、谱面增删改与键盘输入全部锁定，需停止后才能编辑（悬浮窗发起的播放同样生效）
- 曲谱保存：自动持久化（Tauri 模式存应用数据目录 `songs.json`，浏览器预览存 localStorage），支持单个谱面导出 / 导入 JSON（兼容旧版单音格式）

## 记谱格式

括号内字母同时按 = 一拍；单独字母 = 一拍；空格分隔拍；`/` 为小节线（不占拍）。例：

```
(CNAE) (NDE)/ (NAE)/ (ADE)/C(DH) /
```

`(CNAE)` = 一拍内同时按下 C、N、A、E；`C` = 一拍内单独按 C。

## 使用方法

1. **编辑**：点格子选中一个音符，点音符面板或直接按字母键为选中音符添加/移除音（再点/再按一次即移除，可拼出和弦）；在「时长」栏选择时值（十六分~全音符及附点）应用到选中音符，同时作为后续新音符的默认时值；「＋ 音符」末尾追加空音符、「－ 删除」删除选中音符。`←`/`→` 移动选中，`Delete` 清空和弦，`空格`/`0` 清空并前进。工具栏可设置「每小节拍数」（拍号）、BPM 与倒计时。
2. **多谱面**：谱面栏「＋ 新谱面」新建，双击谱名重命名，`×` 删除，单击切换。
3. **试听**：点「🎧 试听」在应用内用钢琴采样预览当前谱面旋律（首次会先加载采样），「■ 停止」结束；试听中同样锁定编辑。
4. **管理员权限**：首次启动会弹出 **UAC 确认**（以管理员身份运行）——鸣潮以管理员权限运行，普通权限的按键注入会被 Windows UIPI 拦截，因此必须管理员。若你拒绝 UAC，应用仍可编辑/试听，但向游戏发送按键不会生效（界面会提示"需管理员"）。
5. **播放**：点「▶ 播放」（或悬浮窗「▶ 开始」），若检测到游戏进程会自动切换过去；倒计时结束后开始按谱发送按键——倒计时期间若无自动跳转则**切换到目标游戏窗口**。播放中切出游戏会自动停止（防止误发按键）。播放中可暂停（自动松开按键）/继续/停止。
6. **悬浮窗**：点「🪟 悬浮窗」打开置顶小窗，显示谱名，可开始/暂停/结束、调整倒计时、◀▶ 切换谱面；顶部空白处可拖拽移动。
7. **保存**：编辑内容自动保存；「导出」当前谱面为 JSON，「导入」追加为新谱面。
8. **退出**：点主窗口关闭按钮会弹出确认——「完全退出」结束全部进程，「最小化到托盘」隐藏主窗口继续后台运行（从托盘图标恢复）。

## 在 Windows 上构建

前置条件：[Rust 工具链](https://rustup.rs/)（MSVC 目标）+ [Tauri 2 的 Windows 依赖](https://v2.tauri.app/start/prerequisites/)（WebView2 Runtime 在 Win10/11 中已内置）。

```powershell
cd src-tauri
cargo build --release
# 产物：src-tauri/target/release/wuwa-music.exe
```

> 若需要打成安装包（.msi/.exe 安装器），可安装 `cargo install tauri-cli` 后执行 `cargo tauri build`（需先在 `tauri.conf.json` 的 `bundle` 中配置图标）。


## 说明

- 音符编号协议（前端 → Rust）：`1~7`=低八度，`8~14`=中八度，`15~21`=高八度；每个音符事件 = `{ ids, ticks }`，`ids` 为和弦编号数组（空 = 休止，最多 8 音），`ticks` 为时值（单位 1/4 拍：4 = 四分音符）
- 每个音符按键按其时值的 70% 按住、剩余 30% 松键，避免音符粘连
- 音高约定（试听）：简谱 1=C 大调，中八度 1 = C4；低八度 C3 起、高八度 C5 起
- 按键使用扫描码（`KEYEVENTF_SCANCODE`）发送，兼容按扫描码读取输入的游戏
- 非 Windows 平台可编译运行，但按键模拟仅打印日志（用于开发调试界面）
