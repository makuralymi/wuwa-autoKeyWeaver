# 鸣朝古琴曲谱编辑自动播放器（keyweaver）

基于 **Tauri 2 + Rust + winapi** 的曲谱编辑与按键模拟工具：可视化编辑曲谱，播放时按曲谱自动模拟键盘按键（适用于鸣潮乐器演奏等按键盘触发的场景）。

## 功能

- 可视化曲谱编辑：自定义拍数（1~1024）、自定义速度（BPM 20~600）
- **支持和弦**：每拍可填入多个同时按下的音符（对应括号记谱），点音符面板或按字母键即可添加/移除
- 21 个音符：简谱 1~7 的低 / 中 / 高三个八度（低八度下加点、高八度上加点），另含休止符
- 按键映射（键盘字母区每排从左到右 7 键）：

  | 八度 | 音符 | 按键 |
  |------|------|------|
  | 高八度 | 1~7（上加点） | `Q W E R T Y U` |
  | 中八度 | 1~7 | `A S D F G H J` |
  | 低八度 | 1~7（下加点） | `Z X C V B N M` |

- **内置默认谱面**：《远航星的告别》（by B站 掉漆桌），已解析为 670 拍和弦谱，首次启动自动加载
- 播放曲谱：按 BPM 节奏用 winapi `SendInput`（扫描码方式）模拟按下/松开和弦按键
- **多谱面管理**：新建 / 重命名（双击）/ 删除 / 快速切换，各谱面独立保存拍数与 BPM
- **倒计时**：播放前可设置 0~60 秒倒计时（留出切换到游戏窗口的时间），倒计时期间可暂停/停止
- **悬浮窗**：置顶无边框小窗，可拖拽，展示当前谱名，含 开始 / 暂停 / 结束 / 倒计时调整 / 切换谱面；播放时实时显示倒计时与当前拍进度
- 播放时主界面实时高亮当前拍；暂停时自动松开按键、恢复时重新按下
- 曲谱保存：自动持久化（Tauri 模式存应用数据目录 `songs.json`，浏览器预览存 localStorage），支持单个谱面导出 / 导入 JSON（兼容旧版单音格式）

## 记谱格式

括号内字母同时按 = 一拍；单独字母 = 一拍；空格分隔拍；`/` 为小节线（不占拍）。例：

```
(CNAE) (NDE)/ (NAE)/ (ADE)/C(DH) /
```

`(CNAE)` = 一拍内同时按下 C、N、A、E；`C` = 一拍内单独按 C。

## 使用方法

1. **编辑**：单击拍格选中，点上方音符面板或直接按键盘对应字母键为选中拍添加/移除音符（再点/再按一次即移除，可拼出和弦）。`←`/`→` 移动选中，`空格`/`0` 清空当前拍并前进，`Delete` 清除当前拍。
2. **多谱面**：谱面栏「＋ 新谱面」新建，双击谱名重命名，`×` 删除，单击切换。
3. **播放**：点「▶ 播放」（或悬浮窗「▶ 开始」），倒计时结束后开始按谱发送按键——倒计时期间**切换到目标游戏窗口**。播放中可暂停（自动松开按键）/继续/停止。
4. **悬浮窗**：点「🪟 悬浮窗」打开置顶小窗，显示谱名，可开始/暂停/结束、调整倒计时、◀▶ 切换谱面；顶部空白处可拖拽移动。
5. **保存**：编辑内容自动保存；「导出」当前谱面为 JSON，「导入」追加为新谱面。

## 在 Windows 上构建

前置条件：[Rust 工具链](https://rustup.rs/)（MSVC 目标）+ [Tauri 2 的 Windows 依赖](https://v2.tauri.app/start/prerequisites/)（WebView2 Runtime 在 Win10/11 中已内置）。

```powershell
cd src-tauri
cargo build --release
# 产物：src-tauri/target/release/wuwa-music.exe
```

> 若需要打成安装包（.msi/.exe 安装器），可安装 `cargo install tauri-cli` 后执行 `cargo tauri build`（需先在 `tauri.conf.json` 的 `bundle` 中配置图标）。

## 项目结构

```
├── dist/                  # 前端（纯 HTML/CSS/JS，无需构建）
│   ├── index.html         # 主编辑器
│   ├── overlay.html       # 悬浮控制窗
│   ├── store.js           # 共享层：数据访问 / 事件 / 音符映射
│   ├── app.js             # 主编辑器逻辑
│   ├── overlay.js         # 悬浮窗逻辑
│   └── style.css
└── src-tauri/
    ├── Cargo.toml
    ├── tauri.conf.json    # 双窗口配置（main + overlay 置顶悬浮）
    ├── capabilities/default.json
    └── src/
        ├── main.rs        # 谱面存储、播放/暂停/停止/倒计时、节奏控制
        └── keyboard.rs    # winapi SendInput 按键模拟（非 Windows 平台为预览 stub）
```

## 说明

- 音符编号协议（前端 → Rust）：`0` 或空数组 = 休止，`1~7`=低八度，`8~14`=中八度，`15~21`=高八度；每拍是一个编号数组（同时按下的和弦），最多 8 音
- 每拍按一拍时长的 70% 按住，剩余 30% 松键，避免音符粘连
- 按键使用扫描码（`KEYEVENTF_SCANCODE`）发送，兼容按扫描码读取输入的游戏
- 非 Windows 平台可编译运行，但按键模拟仅打印日志（用于开发调试界面）
